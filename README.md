## 🌟 درباره پروژه

**Nebula Player** یک پخش‌کننده‌ی موسیقی تحت وب است که با هدف ارائه‌ی تجربه‌ای زیبا و مدرن برای مدیریت و پخش لیست‌های پخش ساخته شده است. این پروژه با الهام از طراحی‌های مینیمال و فضایی (نظیر اسپاتیفای) طراحی شده و از فایل‌های `M3U8` خروجی پلیرهای ویندوزی پشتیبانی می‌کند.

با Nebula Player می‌توانید لیست پخش خود را به صورت خودکار بارگذاری کنید، برای هر آهنگ کاور اختصاصی (بر اساس نام خواننده) تولید کنید و یک تجربه‌ی کاربری روان و آفلاین داشته باشید.

---

## ✨ ویژگی‌ها

- **🎵 پشتیبانی از فایل‌های M3U8:** به راحتی لیست پخش خود را از پلیرهای ویندوزی import کنید.
- **🎨 طراحی گلس‌مورفیسم (Glass-morphism):** ظاهری شیشه‌ای، مدرن و جذاب با افکت‌های blur و شفافیت.
- **🌌 پس‌زمینه‌ی گرادیان متحرک:** انیمیشن‌های کهکشانی و پویا که به سایت روح می‌بخشند.
- **🖼️ تولید خودکار کاور:** بدون نیاز به API، کاورهای منحصر‌به‌فرد برای هر آهنگ ساخته می‌شود.
- **🔍 جستجوی پیشرفته:** قابلیت جستجوی لحظه‌ای در لیست پخش با هایلایت کردن نتایج.
- **🎧 پخش آفلاین:** با استفاده از IndexedDB، فایل‌های صوتی را در مرورگر ذخیره و پخش کنید.
- **⌨️ شورت‌کات‌های صفحه‌کلید:** کنترل کامل پلیر با کیبورد (Space، فلش راست/چپ).
- **📱 واکنش‌گرا (Responsive):** تجربه‌ی کاربری عالی در تمام دستگاه‌ها (موبایل، تبلت، دسکتاپ).
- **📝 نمایش متن آهنگ (Lyrics):** امکان افزودن و نمایش متن آهنگ به صورت دستی.
- **💾 ذخیره‌سازی وضعیت:** موقعیت پخش و آهنگ فعلی در مرورگر ذخیره می‌شود.

## 🚀 شروع سریع

برای اجرای پروژه به صورت محلی، مراحل زیر را دنبال کنید.

### پیش‌نیازها

- Node.js (نسخه 18 یا بالاتر)
- npm یا yarn

### مراحل نصب

1.  کلون کردن مخزن
    ```sh
    git clone https://github.com/mehrdadmb2/Nebula-Player.git
    cd Nebula-Player
    ```

2.  نصب وابستگی‌ها
    ```sh
    npm install
    # یا
    yarn install
    ```

3.  قرار دادن فایل پلی‌لیست
    فایل `playlist.m3u8` خود را در پوشه‌ی `public/` قرار دهید.

4.  (اختیاری) تنظیم متغیرهای محیطی
    اگر می‌خواهید از APIهای اسپاتیفای یا جینیوس استفاده کنید، یک فایل `.env` بر اساس `.env.example` بسازید و کلیدهای خود را وارد کنید.

5.  اجرا در محیط توسعه
    ```sh
    npm run dev
    # یا
    yarn dev
    ```

6.  ساخت نسخه‌ی نهایی
    ```sh
    npm run build
    # یا
    yarn build
    ```

│   └── workflows/

├── public/
│   ├── music/                  # فایل‌های صوتی (اختیاری)
│   └── playlist.m3u8           # فایل پلی‌لیست شما
├── src/
│   ├── api/                    # ارتباط با APIهای خارجی
│   ├── assets/                 # فایل‌های استاتیک
│   ├── components/
│   │   ├── modals/             # مودال‌ها (مثل مودال لیریکس)
│   │   ├── playlist/           # کامپوننت‌های لیست پخش
│   │   ├── ui/                 # کامپوننت‌های UI کوچک
│   │   ├── NowPlaying.jsx      # پلیر اصلی
│   │   └── SearchBar.jsx       # نوار جستجو
│   ├── context/                # Context API برای مدیریت وضعیت
│   ├── hooks/                  # هوک‌های سفارشی
│   ├── styles/
│   │   └── globals.css         # استایل‌های全局
│   ├── utils/                  # توابع کمکی
│   ├── App.jsx                 # کامپوننت اصلی
│   └── main.jsx                # نقطه‌ی ورود
├── .env.example                # نمونه فایل متغیرهای محیطی
├── .gitignore
├── index.html
├── package.json
├── postcss.config.js
├── tailwind.config.js
├── vite.config.js
